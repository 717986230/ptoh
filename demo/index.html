模块 1

万能 JSON 配置协议（Template DSL）

步骤 1 的交付物。先用 TypeScript 定义完整结构——渲染器、后台、校验器共用同一份类型；再给一份可直接上线的JSON 示例，包含 Avatar 头像、Text 昵称、RandomText 随机签文、QRCode 小程序码四类图层和广告解锁规则。

types/template.d.ts — 数据结构定义
图层 type用途关键字段
avatar用户头像，圆形 / 圆角裁剪，带描边。必须有 fallback：拿不到头像时用昵称首字生成色块头像，绝不留空。x, y, r, borderColor, fallback
text绑定用户数据的文字：昵称、自定义输入、日期等。支持自动换行与超长自动缩小字号。bind, fontSize, color, maxWidth, maxLines
randomText从 pool 词库按 seed 抽一条：签文、测试结果、今日状态。seed 决定结果，所以分享才能还原。pool[], seedKey, titleSize, bodySize
qrcode带参小程序码占位图层。注意：真码必须由云函数调 wxacode.getUnlimited 生成并缓存到 OSS，前端只负责把图片画上去。scene, size, page
staticText / image模板自带的标题、装饰字、贴纸图，内容写死在配置里。value / src, x, y

模块 2

Canvas 核心渲染器（Core Renderer）

步骤 2 的交付物。一个与模板无关的渲染类：吃任意一份模块 1 的 JSON，按图层顺序依次绘制，导出时按 dpr 放大保证高清；水印直接画进像素层，未解锁的导出图无法裁掉。下面是可直接搬进小程序 / Uni-app 的 TypeScript 版，本页工作台运行的是同一套逻辑的 Web 版。

渲染管线（固定 6 步）

  • 加载底图：先下载到本地临时路径再绘制，失败自动降级为 theme 渐变底色，永不白屏。
  • 头像裁剪：save → arc clip → cover 方式铺满 → restore，再描金边。
  • 文字排版：按字符逐字测宽做中文换行；超 maxLines 时自动缩小字号而不是截断。
  • 随机图层：结果 = pool[seed % pool.length]，同 seed 必同结果，分享还原靠它。
  • 水印层：locked 时最后绘制半透明斜纹水印，进像素、不可后期去除。
  • 高清导出：离屏 Canvas 按 750×1334 设计稿 × dpr(2~3) 渲染后导出 PNG。

PRD 里修正的 3 个坑（已落进代码）

  • 头像拿不到：微信已禁止静默获取头像昵称，必须走 chooseAvatar 按钮 / 用户上传，所以 Avatar 图层强制带 fallback。
  • 小程序码不能纯前端生成：QRCode 图层只接收云函数生成好的图片 URL（按 template_id + source_uid 缓存）。
  • JSON 不能走云函数拉：配置放静态托管 + CDN、带 version 字段；本地内置一份兜底 JSON，CDN 挂了自动降级。

模块 3

裂变路由 & 一个方法复制 1000 次

引擎只写一次。复制的不是代码，是「底图 + 文案池 + 一段 JSON」这个组合包。先用 10 个模板测出分享率最高的公式，再批量套用到其他主题——代码能复制 1000 次，爆款靠内容产能。

STEP 1A 生成

A 抽签得到 seed=7 的结果，seed 与结果一起写入轻量打点，生成带参分享卡片。

STEP 2带参分享

路径携带 template_id + source_uid + seed，好友点开无需登录即可见 A 的海报。

STEP 3B 还原

页面按 seed 重算 randomText，像素级还原 A 的签文，再弹「我也要测」引导 B 生成自己的。

STEP 4风控降级

CDN / 云函数异常时自动切本地内置 JSON 兜底模板，业务不中断；广告加载失败改走分享解锁。

批量复制流水线（上新一个模板 ≈ 15 分钟）

  • 选题：蹭节日 / 热点 / 情绪点（求签、发疯文学、工资条、准考证……）。
  • 底图：AI 批量出图 → 统一裁成 750×1334 → 上 OSS 开 CDN。
  • 文案池：每个模板 10~20 条结果文案，AI 起草 + 人工过一遍梗和风险词。
  • 配置：复制上一份 JSON，只改 id、底图、pool 和坐标，版本号 +1。
  • 灰度：先小流量看生成率 → 分享率 → 解锁率，数据差的模板直接下架换新。

App 端的差异（先说清）

  • 渲染器可复用：Canvas 逻辑换成 Web Canvas / Flutter Canvas 即可，JSON 协议完全不用改。
  • 裂变摩擦变大：小程序点开即玩；App 要先下载安装，必须配微信分享 SDK、邀请码、口令等方式补摩擦。
  • 变现替换：流量主激励视频换成穿山甲 / 优量汇等广告 SDK，unlock_mode 字段不用改，仍是 "ad"。
