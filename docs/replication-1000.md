# 一个方法复制 1000 次的流水线

一个渲染器 + 1000 个 JSON = 1000 个玩法，不用改代码、不发版。

## 1. 先测 10 个，找爆款公式

不要一上来做 1000 个。先上 10 个模板（求签、打工人、准考证、工资条娱乐版、MBTI、新年红包等），看 3 个数：

- 打开率
- 生成率（打开后点了生成）
- 分享率（生成后点了分享）

分享率最高的 1-2 个公式，就是值得复制的公式。

## 2. 模板库结构

```
templates/
  new-year-fortune.json   # 模板 JSON
  worker-status.json
  exam-fun.json
  library.json            # 模板列表 + 分类 + 排序 + 是否上架
```

`library.json` 示例：

```json
{
  "version": 12,
  "templates": [
    { "templateId": "new-year-fortune-2026", "title": "新年求签", "cover": "https://cdn.../cover.jpg", "enabled": true }
  ]
}
```

小程序启动时拉一次 `library.json`（CDN），按版本缓存。

## 3. AI 批量生成

给 AI 一个固定 prompt 模板，只换主题词：

- 主题：新年 / 情人节 / 开学 / 双十一 / 春节 / 毕业季
- 词库：每个模板 10-20 条签文 / 结果文案
- 背景图：AI 生图，统一 750x1334，风格固定

人工只审三件事：文案不踩线、图不侵权、合规声明在。

## 4. App 版裂变差异

小程序是“打开即玩”，App 要下载安装，转化低很多。App 版要加：

- 邀请码 / 口令红包
- 微信 Share SDK 分享卡片
- 落地页先出结果图，再引导下载

1000 个复制 ≠ 1000 倍增长，内容和时机才是瓶颈。先找到爆款公式，再批量复制。
